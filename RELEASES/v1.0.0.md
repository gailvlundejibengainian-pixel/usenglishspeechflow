# Release: v1.0.0 - Local Codespace-ready prototype

Version: v1.0.0
Date: 2026-08-14
Branch merged: feature/ui-improvements, feature/bugfix-empty-file -> main

Notes:
- This version includes:
  - Frontend: improved UI with word-level highlighting (green = correct, yellow = missing, red = wrong), play controls for both your recording and browser TTS, and word-accuracy scoring.
  - Backend: Groq Whisper integration for transcription, plus server-side checks to prevent empty-file uploads and better logging.
- Intended usage: local development or GitHub Codespaces. Not for public deployment without securing keys and adding rate limits.

How to run (local / Codespaces): see README.md

If you want to roll back this release, checkout the previous commit on main or use git revert on the merge commit.
